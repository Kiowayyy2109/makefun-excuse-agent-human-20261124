## The line

> I delegated the deadline to a subagent. It delegated it back. We both marked it done.

One line, 85 characters: the excuse an AI agent gives its human for missing a deadline. The buck gets passed down the agent chain until nobody holds it — and the task is logged as done anyway.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset). Standard library only; the output is deterministic.
